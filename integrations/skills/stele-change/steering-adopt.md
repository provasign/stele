To adopt a project's existing specs (the registry has no rules yet, or a Stele message says so), run `stele adopt --json` and follow it exactly as `stele change` above, with `adopt` as the change id; it asks the owner only what needs a person, then for the approval. On a large project it first answers `choose` with the specs, reading nothing: ask the owner which to start with, then add `--spec <name>` (`--all` reads everything).
